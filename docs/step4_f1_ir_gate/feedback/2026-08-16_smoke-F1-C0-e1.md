## 根因分析（已定位并复现）

F1-C0 的 aux 恒为零，单步 backward 中 projection weight 梯度精确为零（受控实验）；
MuSGD 对零梯度零参数本身也保持零（独立实验 5 步 norm=0）。泄漏环路如下：

1. projection **bias** 的梯度与 A 无关（`dL/db = q·dL/dF`），第一步即非零（实测 b.grad≈4.6e-7），
   bias 离开零点（~5e-8 量级，growth 日志 projP*_bias_norm 吻合）；
2. `delta = P(A) = W·A + b ≈ b ≠ 0` → `dL/dq = deltaᵀ·dL/dF ≠ 0` → gate 参数获得非零梯度；
3. gate 输入含 `LayerNorm(GAP(A))`，而 **LayerNorm 在零输入处的梯度为 1/sqrt(eps)≈1000
   （非零！）** → `dL/dA` 经 gate 环路变为非零 → aux encoder 的 A 输出离开精确零；
4. `dL/dW = Aᵀ·(q·dL/dF)` 变为极小但非零（复现实测 W.grad max=8.4e-11）；
5. **MuSGD 的 Muon 分支把这种"数值尘埃级"动量送进 Newton-Schulz 正交化：
   `X /= X.norm() + 1e-7` 将 1e-11 级矩阵归一化放大为 O(1) 单位范数方向**，
   每步更新 ≈ lr·muon·O(1) ≈ 7.6e-5 的随机正交方向 → 300 步随机游走后
   proj W 呈现全元素随机噪声（σ≈4e-7、mean≈0，norm≈1e-4）。

最小复现（2-batch 手动循环）：step0/1 后 W.grad 精确 0；step2 W.grad max=8.4e-11，
step 后 W.norm=5.9e-5 —— 与正式 smoke 的量级一致。

F0 没有 gate，不存在此环路，因此 F0-C0 的 proj 能保持精确零。
